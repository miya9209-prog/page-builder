# MISHARP PAGE BUILDER

미샵 4050 여성의류 상세페이지 원고 생성기 (Streamlit).

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Secrets에 `OPENAI_API_KEY`가 필요합니다.

## 원고 생성

- 입력한 소재, 디테일, 실측, 핏, 세탁법을 바탕으로 초안 작성 → 검수 → 필요한 경우 국소 재편집
- 사진이 있으면 별도의 시각 특징 확인 단계를 거쳐 **사진으로 확인 가능한 외관**을 원고 작성 근거에 전달
- 사진 관찰에 의한 디테일은 직원이 확인해야 하며, 촉감·착용감·보온성·제조국 등은 사진으로 확정하지 않음
- 제조국을 비워두면 원고 생성을 시작하지 않고 입력 요청 (기존 출력에서 제조국 공란이 생성된 문제 방지)
- 핵심 실측 수치 불일치, 근거 없는 힙 커버·이너 착용 보장, 털 빠짐 과장 등을 자동 검토·보정
- 남은 검토 사항은 UI의 **원고 사실확인 필요 항목**에 표시 (정상 원고 다운로드는 차단하지 않음)

## 기존 형식 유지

TXT 다운로드, HWP 다운로드 버튼, 후기와 FAQ 사이 구분선, 사이즈 팁 4종 표기, 기존 HTML 소스 출력, 상품 네이밍을 유지합니다.

**파일형식 관련 기존 구조:** 현재 'HWP 다운로드'는 내부에서 `python-docx`로 문서 바이트를 생성해 `.hwp` 확장자로 제공하는 종전 구현입니다. 이 버전에서는 기존 업무 호환성을 위해 해당 구조를 바꾸지 않았습니다. 실제 네이티브 HWP 파일이 필요한 경우 별도 포맷 전환 개발이 필요합니다.

## 테스트

python -m unittest discover -s tests -v
